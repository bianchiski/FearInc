# linked-list

## Simple version

This is a friendly introduction to linked-list. Start with a tiny example and follow what changes before worrying about exact terminology.

## Interview version

Identify the input, output, edge cases, and expected time and extra-space cost before coding.

## Common traps

- Forgetting empty or very small inputs.
- Coding before explaining the idea.

### Tiny glossary

- **Input:** what the code receives.
- **Output:** what the code returns.
- **Edge case:** an unusual input that can reveal a bug.



## New learner checkpoint

Before solving, say the input, output, and one edge case in your own words. If a term feels unfamiliar, use the glossary and then return to the exercise.
